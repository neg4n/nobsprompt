Initialize the opinionated prompt in `~/.zshrc`:

```zsh
eval "$(nbsp init zsh --autosuggest)"
```

This recommended setup includes bounded autosuggestions. If another ghost-text
plugin is already active, omit `--autosuggest`; the prompt itself is unchanged.

The output is one line:

```text
/U/i/D/p/nobsprompt [main +1 ~2 ?3 ^1] [node:22.14.0] [2.4s] [jobs:2] %
```

## Segments

On a successful collection, the physical working directory returned by
`getcwd()` is visible. Parent segments are abbreviated to their first
character (with the leading dot retained for hidden parents), while the final
segment remains intact. If `getcwd()` fails, `nbsp prompt` exits with status 1
and writes no prompt; the bundled integration uses its plain `> ` fallback.

Other segments appear only when they carry useful information:

| Segment | When it appears |
| --- | --- |
| Git | A repository is discovered and current HEAD or a cache snapshot supplies a branch label |
| Node | The final `NVM_BIN` component, or its parent when a final `bin` has a preceding component, is a 1-255-byte ASCII label containing only letters, digits, `.`, `-`, or `_`; one leading `v` before a digit is removed |
| Duration | The previous command lasted at least 2 seconds |
| Jobs | One or more background jobs exist |
| Failure | The previous command returned a nonzero status |

The Git markers are:

| Marker | Meaning |
| --- | --- |
| `+` | Porcelain records with staged changes |
| `~` | Porcelain records with worktree changes |
| `?` | Untracked porcelain records |
| `!` | Unmerged porcelain records |
| `^` | Commits ahead of upstream |
| `v` | Commits behind upstream |
| `*` | Stashes |

## Exact failure status

Successful commands leave the prompt character clean. Failures preserve the
exact status and join it to Zsh's native `%#` prompt character:

```text
e1%
e127%
```

Only the failure state is colored red. Path and Git text use the terminal's
default foreground rather than assuming a palette slot.

## Fixed presentation

The built-in colors, symbols, segment visibility, two-second duration
threshold, layout, and `%#` prompt character are not configurable.

:::note
`NBSP_CACHE_DIR` and `NBSP_GIT_TIMEOUT_MS` are operational controls, not
presentation settings. Use detached mode for presentation changes.
:::

## Shared shell behavior

The opinionated and detached modes use the same Zsh lifecycle for timing, jobs,
asynchronous Git refresh, redraw correction, and a private external-editor
widget. Initialization binds `Alt+E` in `emacs`, `viins`, and `vicmd` only when
that key is undefined, preserving existing bindings and Zsh's public
`edit-command-line` widget. With vi, vim, or nvim, a valid final cursor report
restores the editor cursor position when the command returns to Zsh; an absent
or invalid report places it at the end.
